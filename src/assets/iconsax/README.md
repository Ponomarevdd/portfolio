# Iconsax SVG subset

Iconsax: https://iconsax.dev/
SVG sources: https://github.com/rendinjast/iconsax-react/tree/master/icons
License: MIT, included in LICENSE.

Bold: layer, monitor, element-4, pen-tool, mobile.
Linear: arrow-up (displayed rotated 45 degrees for the contact link).
Fixed fill/stroke colors use currentColor. Missing viewBox attributes are normalized to 0 0 24 24 so icons scale without clipping; original SVG paths are preserved.
