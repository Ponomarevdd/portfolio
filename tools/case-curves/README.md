# Кейс: текст макетов в кривые

На странице кейса весь текст макетов (Geologica) рисуется SVG-кривыми, поэтому файлы шрифта не грузятся.
Каждое слово — отдельный маленький `<svg>` в строке, так что браузер переносит строки так же, как живой текст,
на любой ширине. Пробелы и высоту строки даёт встроенный в страницу кусочек шрифта с одним пробелом (~0,6 КБ).

- `measure.cjs` открывает собранную страницу с подключённым Geologica и меряет каждое слово (позиции букв, базовую линию),
  а также подписи, которые меняет анимация LMS в `school-case.ts`.
- `build.py` берёт глифы из `@fontsource/geologica` и пишет `site/src/data/curves/my-school.json`.
- `site/integrations/curves.mjs` после сборки подставляет кривые в HTML. Если текст страницы изменился,
  сборка падает с просьбой перегенерировать.

После правки текста в макетах кейса: поднять сервер `python3 -m http.server 4399 --bind 127.0.0.1 -d site/dist`
и запустить `./run.sh`. Нужны `playwright` (Chromium) и `pip install fonttools brotli`.
В `astro dev` текст макетов показывается запасным шрифтом: кривые появляются только в сборке.
