# Портфолио — локальный прототип

Astro + TypeScript + GSAP. Главная с адаптивной сеткой и анимациями. Референс: `../concepts/round-04-concept-01.png`.

## Запуск

Node.js 22.12+ (рекомендуется 24), pnpm.

```sh
pnpm install
pnpm dev
```

Открыть адрес, который выведет Astro (обычно http://127.0.0.1:4321).

```sh
pnpm check
pnpm build
```

## Где менять

- `src/data/projects.ts` — демонстрационные кейсы, данные кейсов, категории и обложки (годы пока не выводятся).
- `src/pages/index.astro` — интро и композиция главной.
- `src/styles/global.css` — отступы, шрифт, сетка и стекло меню.
- `src/styles/gradient.css` — все настройки градиента в первых строках: цвета, размер, скорость, прозрачность, размытие и зерно. Цвета под карточками меняются вместе с ними.
- `src/scripts/motion-settings.ts` — настройки подъёма, размытия и появления букв, а также движения меню.
- `src/scripts/motion.ts` — появление текста через SplitText и карточек через ScrollTrigger, подъём и размытие букв при наведении; учитывает reduced motion.
- `src/components/ProjectCard.astro` — обложка и подписи снаружи карточки.
- `public/images/` — сгенерированные демонстрационные обложки.

Шрифт Onest включён локально через Fontsource (OFL). Сетка: бенто от 900px; ниже — широкий главный кейс и два соседних; до 600px — одна колонка. Подписи могут переноситься, если для двух категорий не хватает места. Фон переливается через CSS независимо от курсора, останавливается вне экрана и на неактивной вкладке. Меню закреплено сверху; на устройствах с мышью оно и буквы реагируют на указатель. При `prefers-reduced-motion: reduce` анимации отключены. «Контакты» открывают полноэкранную форму (пока только десктоп). Форма демонстрационная: данные не отправляются и не сохраняются; почта и Telegram — отключённые заглушки. Шесть кейсов ещё не ведут на отдельные страницы. Меню подсвечивается только при наведении или фокусе. Категории — метки, не фильтр. Реальных контактных данных нет. Страница закрыта от индексации до наполнения.
